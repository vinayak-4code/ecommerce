E-commerce Backend Demo

Spring Boot API with Product Admin catalog governance, seller product/inventory ownership, customer cart/order flow, coupon enrollment, and a search projection.

Seeded users

  • Product Admin: admin@example.com / Password1 / role PRODUCT_ADMIN
  • Seller: seller@example.com / Password1 / role SELLER
  • Customer: customer@example.com / Password1 / role CUSTOMER

Reviewer flow

  1. Login with each role using /api/v1/auth/login.
  2. Search products with /api/v1/search/products.
  3. Apply one coupon in cart: ELECTRO10, FLAT200, or APPAREL50.
  4. Place an order and observe inventory decrement through reservation + consumption.

Use docs/curl-requests.sh for a complete executable curl script.
