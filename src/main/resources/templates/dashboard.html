Spring Boot Enterprise Demo

E-commerce backend reviewer dashboard

This Thymeleaf UI gives three separate journeys over the same REST APIs. Each page signs in with the seeded role and stores the returned Bearer token in browser storage.

🛡 Product Admin Create categories, sub-classifications, mandatory/optional attributes, and coupons. 🏬 Seller Manage warehouses, products, inventory quantity, and product coupon enrollment. 🛒 Customer Search products, add to cart, apply a single coupon, and place orders.
